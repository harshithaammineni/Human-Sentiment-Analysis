# EEEM068 - Human Sentiment Analysis (MSCTD En-De)

Group coursework for EEEM068 Applied Machine Learning, Spring Term 2026,
University of Surrey. We build a 3-class sentiment classifier (Positive /
Neutral / Negative) for the **English-German (En-De)** portion of the
[MSCTD](https://github.com/XL2248/MSCTD) dataset, combining face-level cues,
full-image context and (extra credit) multimodal text+image fusion.

## How to run locally

We run the notebooks from VS Code/Jupyter using the local CPU kernel
`CNN Local CPU (Python 3.13)`. The selected kernel must be able to see the
whole project folder, including `src/` and `data/raw/`.

1. **Open the project folder in VS Code** and pick
   `CNN Local CPU (Python 3.13)` from the notebook kernel picker. Use the
   Windows project folder as the notebook root.
2. **Edit `scripts/data_sources.json`** — open the
   [MSCTD README](https://github.com/XL2248/MSCTD), find the three
   Google Drive links for the En-De **train / dev / test** image zips,
   and paste the long alphanumeric `FILE_ID` from each share URL into
   the corresponding field.
3. **Run the one-click setup** — from a terminal at the project root:
   - **Windows**: `scripts\setup_data.bat`
   - **PowerShell**: `pwsh scripts/setup_data.ps1`
   - **bash**: `bash scripts/setup_data.sh` *(see Linux/macOS section below)*

   This installs Python deps, clones MSCTD for the 9 text/label files,
   downloads + extracts the image zips into `data/raw/images/{train,dev,test}/`,
   and verifies the layout.
4. **Open notebooks in order** in VS Code: `01 → 02 → 03 → 04 → 05 → 06 → 07`.
   Each notebook imports from `src/` and writes
   metrics/figures into `outputs/`.

> **Tip:** if you already downloaded the image zips manually, run
> `python scripts/download_data.py --local-zip-dir <folder>` instead —
> no Google Drive IDs needed.

> **Tip:** to get started before the images finish downloading you can
> run `python scripts/download_data.py --skip-images` to pull just the
> text/label files (MSCTD is ~30k utterances across ~3k scenes, so this
> step alone exercises the dataset code).

## Reproducing results

All notebooks set a fixed seed via `src.utils.seed_everything(42)`. The
final model comparison is regenerated by Notebook 06 and saved to
`outputs/tables/final_model_comparison.csv`.
